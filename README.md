# CLOTH X CLUB - QR Payment & Loyalty System V2.0

A lightweight, serverless QR payment, registration, and loyalty tracking module for CLOTH X CLUB.

## Features
- **Single QR Scan Journey:** One scan allows payment, customer onboarding, rewards tracking, and review links.
- **Direct UPI Intent:** Generates prefilled `upi://pay` links for instant app opening.
- **Server-Side PIN Authentication:** Staff access secured via Apps Script Script Properties.
- **Loyalty Rewards Engine:** Earn 1 pt / ₹100 spent (₹0.10 value/pt).
- **Google Sheets Backend:** Zero paid database cost; auto-setup database tables.
